# HerebeEvils
A textbook for the fundamental rules of my universe.

Please note that some entries will periodically be updated so be sure to reread some of them. You might also notice that the writing is inconsistent; this is because English is my second language.

## Folder Symbols

Certain folders use East Asian characters as reading markers.

| Symbol | Meaning | Usage |
|---------|---------|---------|
| 話 | Story | The folder contains story material and may include spoilers. |
| 終 | End | The folder is intended to be read after most other entries. |
| 余 | Extra | Supplemental or optional material. |
