## Folder Symbols

Certain folders use East Asian characters as reading markers.

| Symbol | Meaning | Reading | Description |
|---------|---------|---------|-------------|
| 話 | Story | *Hanashi* (Japanese), *Huà* (Chinese) | Story content. May contain spoilers. |
| 終 | End | *Shū* (Japanese), *Zhōng* (Chinese) | Intended to be read last. |
| 余 | Extra | *Yo* (Japanese), *Yú* (Chinese) | Supplemental or optional material. |
