# HerebeEvils
A textbook for the fundamental rules of my universe.

Please note that some entries will periodically be updated so be sure to reread some of them. You might also notice that the writing is inconsistent; this is because English is my second language.

## Folder Symbols

Certain folders use Japanese/Chinese characters as reading markers.

| Symbol | Meaning | Reading | Description |
|---------|---------|---------|-------------|
| 話 | Story | *Hanashi* (Japanese), *Huà* (Chinese) | Story content. May contain spoilers. |
| 終 | End | *Shū* (Japanese), *Zhōng* (Chinese) | Intended to be read last. |
| 余 | Extra | *Yo* (Japanese), *Yú* (Chinese) | Supplemental or optional material. |
